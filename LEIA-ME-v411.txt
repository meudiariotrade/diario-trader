INSTALAÇÃO GITHUB
1. Extraia o ZIP e envie index.html, sw.js e mercado-v411.css para a raiz do repositório.
2. Confirme que o GitHub Pages fez o deploy da versão publicada.
3. Feche/reabra o app instalado no iPhone; se continuar com a versão antiga, atualize a página e espere o novo cache ser ativado.
4. Confira Mercado -> Jornal -> Painel de mercado e Mercado -> Cotações/Panorama -> Juros/DI.
